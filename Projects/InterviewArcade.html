Date: October 2025
This project was made for the HackNC 2025 hackathon. Interview Arcade is a technical interview practice tool that takes in both code and audio inputs, evaluates them, and provides comprehensive feedback on both. We used React, FastAPI, Gemini, and ElevenLabs. React is used on the frontend to process the inputs. FastAPI allows the frontend to call the backend services -- namely, using Gemini to evaluate code and ElevenLabs TTS for an AI voiceover on the overall feedback. I'm proud to say that we won 1st place in the general track!
